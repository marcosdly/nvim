# nvim

Personal neovim config. Not necessarily minimal, but trynna.

## Installation

### Pieces of the puzzle

- Cascadia Mono (Nerd Font)
- Neovim >= v0.10.0

### Windows

```
scoop bucket add nerd-fonts
scoop install main/neovim nerd-fonts/Cascadia-Code
```

### Linux (debian-based)

Use [`getnf`](https://github.com/getnf/getnf) to fetch and install nerd fonts.

```
nala install -y neovim
getnf -i CascadiaCode
```
